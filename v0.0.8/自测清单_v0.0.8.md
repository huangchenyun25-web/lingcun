# 另存人生 v0.0.8 · 自测清单

> 对象：`v0.0.8/page/index.html`（双击打开，或放到 GitHub Pages 子路径下）+ 《引导协议_v0.0.8》。
> 这一版的核心：**一切在这一页里做出来**，不再把项目说明复制给别的 AI。
> 「断」规则：每个节点结束时，页面都要交给你一个具体的下一步；**点了「保存」之后也一样**。看不到下一步，就记一条卡点。
> 机器自测已跑过（`v0.0.8/_test/test.js`，用模拟 AI，142 项全过；截图在 `page/shots/`）。这份清单给真人走，重点测机器测不了的：真实 AI、真实网络、读起来顺不顺。

## 〇、开测前

- [ ] 用一个**干净的浏览器窗口**（无痕 / 访客），或页面最下面「存档与恢复 → 清空，从头再来」。
- [ ] 想好这次用哪种 AI（二选一，也可以都走一遍；没有密钥也能先走一遍「没密钥」的路，见二·1）：
  - **A｜我的 API 密钥**：手上有 DeepSeek 或通义千问（阿里云百炼）的密钥。
  - **B｜agent**：让 Codex / Claude Code / Grok Bot 打开这一页，并请它用 `?ai=agent` 或 `window.lingcunAI.enable()` 打开 agent 模式（说明写在页面顶部注释和 README 里）。
- [ ] 想好一段你**真做过**的活动或项目（名称、你负责哪块、有没有数据），测复盘案例要用。
- [ ] 准备 1–2 张你自己拍的照片或截图。

## 二、AI 入口（右上角「AI：……」）

| # | 做什么 | 应该看到 | ✔ |
|---|---|---|---|
| 1 | 没填密钥，第一次走到需要 AI 的一步（自己打开，不经 agent） | 「这一步要请 AI 帮忙想」+ 三条路：「填 API 密钥」「还没有密钥？怎么拿一个」「先保存进度，拿到密钥再回来」；**没有 JSON、没有粘贴框、没有「提交结果」、没有 agent、没有「先不用 AI」**（第 86、87 条） | ☐ |
| 1b | 用会被识别成「自动化」的浏览器打开（比如 Chenyun 那台 Mac 上的） | 和上一行一样，**不会**自己进 agent 模式 | ☐ |
| 1c | 展开「怎么拿一个」，点两个官方链接 | 三步大白话；DeepSeek、阿里云百炼的官方密钥页在新窗口打开；没有价格数字 | ☐ |
| 1d | 点「先保存进度，拿到密钥再回来」，关掉页面，再用同一个浏览器打开 | 页面说清怎么回来；重开后有「欢迎回来 · 接着做」，点了回到这一步 | ☐ |
| 1e | 在这一步点「填 API 密钥」，填好点「保存」 | 这一步自己接着往下走，不用重来 | ☐ |
| 2 | 点右上角 | 直接是密钥表单（没有模式可选，没有 agent）；能选 DeepSeek / 通义千问 / OpenAI / 其他；每家有一句实测说明；有一段「密钥只存在这个浏览器里……」的说明和「忘掉密钥」按钮；**没有任何价格数字** | ☐ |
| 3 | 填密钥，点「保存」，再点「测一下能不能连上」 | 「✅ 连上了」；连不上时，提示说清是密钥不对（401）、地址或模型名不对（404）、太频繁或额度用完（429），还是网络/跨域 | ☐ |
| 4 | 点「复制存档链接」，把链接贴到记事本里看 | 链接里**没有**你的密钥 | ☐ |
| 5 | 点「忘掉密钥」 | 提示已删除；之后要 AI 的步骤提示「还没填 API 密钥」，并给「填 API 密钥 / 怎么拿一个 / 先保存进度 / 换一个更小的题目」 | ☐ |
| 6 | （agent 测）让 agent 用 `?ai=agent` 打开页面 | 你在页面上只看到一行「AI 正在帮你想…」，过一会儿出现正常的选择题 / 预览；**任何时候都看不到 JSON、粘贴框、「提交结果」**；agent 交错格式时你也看不到报错原文 | ☐ |
