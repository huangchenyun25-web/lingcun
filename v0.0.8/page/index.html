另存人生 · 先做出第一件东西

在这一页里，一步一步做出一件真能用的小东西。不打卡、不考试、不承诺求职结果。

AI 设置：用你自己的 API 密钥

页面里需要 AI 的几步（追问、做出小网页、写复盘案例、给你一个旁人视角的评价），都用你在这里填的密钥，在这一页里直接跑。以后随时能换一家，或者忘掉密钥。

这一页是由一个 agent（比如 Codex、Claude Code、Grok Bot）替你打开的，它会在后台帮你想，你只要像平常一样做选择。想自己来，在下面填好密钥点「保存」就行。
说清楚三件事：① 密钥只存在这台设备的这个浏览器里（localStorage），不会写进存档链接，也不会发给另存人生；② 你在页面里写的内容，会直接从你的浏览器发给你选的那家模型服务；③ 密钥能花你账户里的额度，别在公用电脑上存，用完可以点「忘掉密钥」。
