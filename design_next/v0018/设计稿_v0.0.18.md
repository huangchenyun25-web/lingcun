## 1. 这一版要解决什么

| 缺口（Astra / 对照） | v0.0.18 怎么接 |
|---|---|
| 主题仍是「改一件小事」 | 开场换成 A1；整条流围绕「用过去经验另存一版生活」 |
| 无「留下与放下」 | 新建 C2 点选屏；选择写入结果依据与分享卡 |
| 方向隐式（创造/学习/转行） | B5 显式「好奇方向」；四问骨架废掉（D4） |
| 结果语义仍是「第一步行动卡」 | D3：仍一条，文案改成「我想试试」+ 组合依据 |
| 登月像通关突破 | E3：另存成功全屏；软化庆祝 |
| 分享像项目宣传 | E4：带走 / 放下 / 想试试 |
| 开图入口 | E9：本版不做真跳转；另存成功页可留「即将接上开图」说明位 |

**仍保留（对照 §3）**：乳白 / 薰衣草 / 墨色 / 得意黑；小人；离线优先 + 库打底 API 润色；语音按住 + 打字；桌面宽屏两栏（入口相关屏）；Rive ST01 / L01 能力可接到新完成态；星图作「玩过的局」；五月天彩蛋藏法；原则不进页面；不写价格。

## 2. 流程总览（废四问后）

```
首页（A1）
  → 带上过去（B3 双入口：经历 / 想改）
  → 留下与放下（C2 点选；背包＝碎片）
  → 好奇方向（B5）
  → 这一版尝试（D3 一条 + 组合依据）
  → 修改这一版（有点想试 / 不像我 / 改一句）
  → 另存成功（E3）
  → 分享（E4）· 星图
```

一局目标：**几分钟内，亲手选出带走与放下，换一个方向，留下一条愿意试的尝试。**  
不宣称「人生突破」；不替用户定终身方向。

与 v0.0.17 对照：

| v0.0.17 | v0.0.18 |
|---|---|
| 首页「不想一直这样过…」→ 找到我的第一步 | A1 开场 →「开始这一版」 |
| 「哪件事想有点不一样？」→ libMatch 三类 → **四问** | 带上过去 → 留下/放下 → 好奇方向（**无四问**） |
| 结果三行：改变什么 / 先做什么 / 今天到哪儿 | 结果：我想试试（主）+ 依据（带走×方向）+ 轻验收 |
| 就它了 → 按住登月 | 有点想试 → 另存成功 |
| 分享：想改变 + 先做了 | 带走 / 放下 / 想试试 |
| 无开图 CTA | 文案位预留，无真链（E9） |

## 3. 分屏文案与状态

### 3.1 01 首页

- **主句（得意黑）**：如果保留过去的经验，换一种接下来的生活，你想试试什么？
- **副句（小字）**：花几分钟，给自己留一个新方向。
- **主按钮**：开始这一版
- 右上角小人 / 星图入口保留；页脚轻署名本版默认关（沿用 v0.0.16 待定习惯，不强制出现「开图的第一步」）。
- **禁止出现**：存档、另存档、创造/学习/转行胶囊、价格、原则条文。

桌面：首页仍可单栏居中；主按钮固定第一屏可见（沿用 v0.0.17 原则）。

### 3.2 02 带上过去（B3）

- **主句**：先带上一件和你有关的事。
- **分段**：`做过的事` | `想改的事`（默认停在「做过的事」；可切换，同一提交框）。
- **占位 / 例子**（点填可改）：
  - 做过：办过线下活动策划；带过团队做内容；学过一段时间吉他；写过公众号但停了
  - 想改：总把想做的事往后放；想碰科技又不知从哪下手；想开始跑步迈不出第一步
- **控件**：语音按住说话（中）+ 打字；桌面 ≥900px 左右两栏（左语音 / 右例子+打字），与 v0.0.17 同构。
- **提交后**：进入「拆碎片」等待（库规则优先；API 可用时润色标签，不可用则本地拆）。

**空 / 太短**：轻提示「多说一点具体的事，后面才能拆开带走和放下」；不进入下一屏。

### 3.3 03 留下与放下（C2 · C4）· **本版新建**

- **主句**：哪些想带走，哪些想放下？
- **副句（一行）**：点一下选；带走的会进你的背包。
- **布局**：
  - 上方：系统拆出的 **2–6 个碎片胶囊**（来自上一句经历/想改）。
  - 每个碎片三个态：未选 / **带走**（填色薰衣草） / **放下**（描边灰紫）。点循环或左右两个小动作——本版推荐：**碎片下方两个字按钮「带走」「放下」**，已选高亮；再点可改。
  - 下方固定区标题：**背包**（仅本屏与结果依据用此词）列出已带走；旁边 **放下** 列出已放下。
- **主按钮**：选好了（至少 1 个带走；放下可为 0，但鼓励至少想一想——若全带走且 0 放下，按钮仍可点，不强迫）。
- **少经历 / 拆不出**：给 3–4 个示例碎片供点选，并保留「这些都不像我」→ 回到 02 重说，或进入「自己写一条带走 / 一条放下」（各一行输入）。
- **星图**：本屏不出现「背包＝项目」；星图入口仍在顶栏，点进去仍是项目列表（C4）。

**选择必须影响结果**：带走集合 + 放下集合写入本局 `take[]` / `leave[]`，进组合与分享；不可只做装饰。

### 3.4 04 好奇方向（B5）

- **主句**：接下来，你更好奇往哪边试试？
- **选项（单选芯片，本版提案名单）**：
  1. 表达（写 / 讲 / 影像）
  2. 科技（工具 / 产品 / AI）
  3. 身体（动起来）
  4. 手作与现场（做出来给人看）
  5. 工作方式（换一种做事节奏）
  6. 其他（自填一词）
- **说明**：不再出现创造 / 学习 / 转行。库匹配改为「方向 × 带走碎片」取材，不作四问问卷。
- **主按钮**：用这个方向看看

### 3.5 05 这一版尝试（D3）

- **形态标签**（小）：这一版 · 一次尝试
- **主卡（得意黑，一屏一句主角）**  
  **我想试试**  
  （一条具体尝试句，例：用你擅长的现场观察，做一期「普通人怎样使用新技术」的内容。）
- **组合依据（次要，可折叠为默认展开两行）**  
  - 带走：观察、讲故事  
  - 方向：科技  
  - （可选一行）放下：反复汇报 —— 仅作依据，不抢主句
- **轻验收（一行小字，可点改）**  
  今天做到这儿就够了：写下题目和三个观察点。  
  （现实类仍默认「一个人能做完」；不默认约人 / 公开发布。）
- **主按钮区**：有点想试（主） · 不像我（次） · 改一句（文字链）
- **禁止**：再跑四问；一次抛 2–3 条尝试（留给以后）；原则说明进页。

### 3.6 06 修改这一版（状态，可与 05 同屏）

| 动作 | 行为 |
|---|---|
| **有点想试** | 进入另存成功前确认（可短按或沿用 L01 按住语感，文案改「另存这一版」） |
| **不像我** | 同屏换一条尝试（同 take/leave/方向）；连续两次仍不像 → 提示可改方向或回 03 改带走/放下 |
| **改一句** | 本地编辑尝试句（优先）+ 可选轻量润色；验收句可点开本地改；失败要明示，不空刷 |

「有点想试 / 不像我」必须让建议**随判断变化**（至少重抽一条或采纳用户改句），避免一次生成定终身。

### 3.7 07 另存成功（E3）

- **全屏完成态标题**：另存成功
- **副句**：你留下了一个愿意尝试的方向。
- **视觉**：星球 / 星作背景装饰可留；ST01 点亮可接在「留下」那一刻；**不要**再写「对我来说确实是大突破」类通关句。
- **主操作**：看这一版（回看尝试卡） · 分享  
- **开图文案位（E9，非真链）**：一行浅字或「更多」里  
  「之后可以带着这一版，去开图制定第一次尝试。」  
  **不可**做成可点外链 / 深链；不要假按钮骗点击。
- **次要**：回星图（本局记入星图项目；名称可用尝试句缩略，不用「存档」）。

按住确认若保留：输入文案与完成回调从「登月」改为「另存」；动画语感可留，语义以本屏为准。

### 3.8 08 分享卡（E4）

```
另存人生                         第 N 次 · 月球（装饰可留）
────────────────────────────────
「繁花 × 科技」（短标题，可改）

我想带走
观察、讲故事                    ［编辑］［隐藏］

我想放下
反复汇报、协调供应商            ［编辑］［隐藏］

我想试试
用现场观察，做一期普通人怎样用新技术的内容
                               ［编辑］

────────────────
你会带走什么？                 ← 给朋友的问题（固定主问）

另存人生 · 2026.10.30
```

- 标题避免「我的人生另存档」作主标题（A6）；可用「我的这一版」或短主题名。
- 隐藏某字段后，导出图与分享文字都不含该字段。
- 「保存成图片」「分享文字」保留；GitHub 不进主文案。
- 分享主问固定：**你会带走什么？**（Astra）；可选次问库以后再加。

### 3.9 09 桌面 · 带上过去（布局延续）

与 v0.0.17 相同原则：≥900px 左＝主句+语音，右＝分段+例子+打字；1280×720 起第一屏可见。留下/放下、方向、结果屏：主操作按钮固定在首屏底部，避免再「下滑才看到问题」。

## 4. 空态 / 少经历 / 不像我（验收要用）

| 场景 | 表现 |
|---|---|
| 02 未输入或过短 | 不进入 03；一行提示 |
| 03 拆不出碎片 | 示例碎片 +「这些都不像我」+ 自填带走/放下 |
| 03 0 带走就点选好了 | 按钮禁用或提示「至少带走一条，后面的尝试才站得住」 |
| 05 库/API 都弱 | 本地模板：`用你带走的「{take0}」，在「{方向}」里做一件今天能完成的小事：{具体}`；标明可改 |
| 不像我 ×2 | 引导改方向或回 03；不死循环空转 |
| 离线 | 全流程可走完；无润色时用库原句；不出现「请联网才能另存」 |

## 10. 设计判断（拍板未写死、本稿代定）

1. **首页主按钮**用「开始这一版」（不用「找到我的第一步」，不用「新存档」）。  
2. **好奇方向名单**用 §3.4 六项；实现时可微调用词，但必须用户可见单选。  
3. **另存确认**优先短主按钮「另存这一版」；L01 按住为可选增强，不挡无 Rive 设备。  
4. **开图文案位**只做说明句，不做可点按钮，避免 E9 下的假跳转。  
5. **旧三行结果**不再作主结构；轻验收降为一行，避免和「我想试试」抢主角。
