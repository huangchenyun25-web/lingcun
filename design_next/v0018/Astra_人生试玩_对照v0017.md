## 0. 一句话差距

| | 现在 v0.0.17 | Astra 人生试玩 |
|---|---|---|
| 主题句 | 「不想一直这样过。先让一件小事不一样。」 | 「如果人生可以另存为」 |
| 用户带走的 | 一件小事的**第一步**（行动卡 / 方案 / 作品）+ 登月星球 | 一段**愿意继续探索的可能**（经历碎片 + 第一次尝试）+ 存档卡 |
| 进开图 | **没有**主按钮（开图署名本版关掉） | 「带着这个存档，去开图看看下一步」→ 开图里**制定第一次尝试** |
| 交互气质 | 说话/打字 + 四问选择题 + 按住登月 | 拖卡片、留下/放下、换组合、改这一版 |

本质：仍是「开图 intro」，但 Astra 把入口从「想改哪件小事」改成「用过去经验另存一版人生」，把终点从「登月 + 分享」改成「存档交给开图去定第一次尝试」。

## 2. 必须改的根因组（附选择题）

### 根因组 A · 主题与开场：从「改一件小事」→「另存一版人生」

**现状**：首页处境句 +「找到我的第一步」；问句是「哪件事想有点不一样」。  
**冲突**：Astra 开场问的是「保留经验、换一种生活」；「存档」一词在 v0.0.10 被刻意弱化（改成登月）。

**选择题**

1. 开场主句怎么定？  
   - **A1** 换成 Astra 句：「如果保留过去的经验，换一种接下来的生活，你想试试什么？」  
   - **A2** 折中：保留「不想一直这样过」处境感，副句改成「给自己留一个新存档」  
   - **A3** 两套文案 A/B 测，本版先做 A1  

2. 「存档」词要不要正面用回来？  
   - **A4** 正面用：另存成功 / 存档卡 / 带着存档进开图（接受和旧「弱化存档」决定冲突，以 Astra 为准）  
   - **A5** 对用户说「另存」「这一版」，内部仍叫存档；主流程少说「存档」二字  
   - **A6** 继续弱化存档，只用「登月 / 星球 / 这一版」表达同一意思  

### 根因组 B · 入口对象：从「想改的事」→「过去的经历」

**现状**：用户说一件想不一样的事 → `libMatch` 分三类 → 四问。  
**Astra**：先带上一件**做过的事**，再拆留下/放下。  
**风险**：纯经历入口对「说不清自己想做什么」的人友好，但可能丢掉 v0.0.16 已跑通的「处境共鸣」。

**选择题**

3. 第一屏用户提交的是什么？  
   - **B1** 只收「一件做过的事 / 一段经历」（Astra 原意）  
   - **B2** 仍收「想改的一件事」，系统在后台拆成经历碎片（用户不感知拖卡）  
   - **B3** 双入口：「说说做过的」为主，「直接说想改的」收进更多  

4. 创造 / 学习 / 转行 三大隐式分流还要吗？  
   - **B4** 保留为内部标签，用户不选（现状）  
   - **B5** 改成「好奇方向」用户显式选（科技 / 表达 / 身体…待定名单）  
   - **B6** 先不做方向枚举，只从经历+放下生成尝试  

### 根因组 C · 「留下与放下」交互（最大新建）

**现状**：无拖拽；无经验碎片物件；背包＝登陆过的项目。  
**Astra**：拖卡进背包 / 放到一边；选择必须影响结果。  
**撞车**：现有「🎒 / 星图」已占用背包心智。

**选择题**

5. 留下与放下怎么做（第一版可落地）？  
   - **C1** 真拖拽：经历卡 → 拆成 2–4 个碎片标签，拖进「带走」/「放下」两区（投入大）  
   - **C2** 轻量版：系统先拆出若干碎片，用户对每条点「带走 / 放下 / 不确定」（无拖，本周可做）  
   - **C3** 更轻：两道题「最想带走一句」「最想放下一句」自填+例子（接近旧转换实验）  

6. 「背包」这个词给谁用？  
   - **C4** 背包＝经验碎片（Astra）；项目列表继续叫星图  
   - **C5** 背包仍＝项目/星球；经验区另名「这一版材料 / 手提箱」  
   - **C6** 本版不出现背包二字，两区就叫「带走」「放下」  

### 根因组 D · 组合与结果：从「一个第一步」→「2–3 个尝试里留一个」

**现状**：库 + 四问 → 一个 `first_step` + `star`；检查三行。  
**Astra**：留下经验 × 好奇方向 → 两三个具体尝试 → 用户留一个。  
**已拍板**：进开图后第一动作＝制定第一次尝试 → 另存人生结尾必须交出「愿意试的那一步 + 支撑碎片」。

**选择题**

7. 结果形态？  
   - **D1** 一次给 2–3 条尝试，用户选一条「另存」；未选的可藏进更多  
   - **D2** 仍只给 1 条主尝试，另两条折叠在「换一条看看」  
   - **D3** 保持现状一个 `first_step`，只改文案包装成「尝试」  

8. 四问还要几道？  
   - **D4** 大幅压缩：经历 → 留下/放下 → 方向 → 出尝试（四问骨架可废或只在后台用）  
   - **D5** 保留 1–2 道关键选择题（如今天能拿多久），其余靠组合生成  
   - **D6** 四问结构保留，只改问句贴「经历/方向」  

9. 交给开图的最小数据包（本版先定字段，对接细节下一轮）？  
   - **D7** 必带：留下的碎片、放下的碎片、选中的尝试句、用户原话；开图按钮文案固定「带着这个存档，去开图看看下一步」  
   - **D8** 同 D7，但开图链本版先做「复制存档摘要 / 说明卡」，真跳转等开图入口核实后再接  
   - **D9** 本版只改文案和结尾 CTA 占位，数据包字段先不定  

### 根因组 E · 庆祝、分享、指标

**现状**：登月＝通关；分享＝想改变 + 先做了；指标含 star 点击。  
**Astra**：登月可留但庆祝「留下愿意尝试的方向」；分享＝带走/放下/想试试；主指标＝保存可能 / 进开图 / 真开始。

**选择题**

10. 登月怎么处理？  
    - **E1** 保留按住登月 + 星球，完成态标题改成「我留下了一个愿意试的方向」（档 A 文案替换）  
    - **E2** 登月动画保留，但主按钮改「另存这一版」；登月降为彩蛋/次要  
    - **E3** 去掉登月通关感，改成「另存成功」全屏（星球作背景装饰）  

11. 分享卡？  
    - **E4** 按 Astra 重做：带走 / 放下 / 想试试 +「你会带走什么？」；可编辑可隐藏字段  
    - **E5** 在现卡上加「带走/放下」两行，保留「我想改变什么」  
    - **E6** 分享先不动，优先做开图 CTA  

12. 开图连接本版做到哪？  
    - **E7** 另存成功页主按钮＝进开图（文案 Astra 原句）；GitHub 进更多  
    - **E8** 主按钮进开图，但先落说明卡（三句话 + 外链），因交接参数未核实  
    - **E9** 仍不做跳转（沿用 v0.0.16 的 1C），只改流程前半

## 4. 与 v0.0.17 能力冲突点（实施时会疼的）

1. **「存档」语义反转**：v0.0.10–17 主流程去「存档」改「登月」；Astra 以「另存为」为题。文案、引导协议、自测用语要统一，否则新旧截图/协议打架。  
2. **背包一词双义**：现背包/星图＝项目；Astra 背包＝经验碎片。必须先定 C4/C5/C6，再动 UI。  
3. **无拖拽基础设施**：页面是表单+选项+按住，没有拖放、没有碎片实体。若选 C1，工作量≈新交互层，不宜和文案小改同一版硬塞。  
4. **结果从 1 条变 2–3 条**：`out.first_step` / 三行结构 / 行动卡·方案·作品形态 / `star_by_q4` 都假设单一步骤；多尝试要改数据模型与检查屏。  
5. **开图主 CTA 缺失**：现 dock＝分享+GitHub；加「带着存档去开图」会挤掉或降级分享/star——和「star 次要」一致，但要改结束页信息架构。  
6. **庆祝文案**：现有「这一步虽小，对我来说确实是大突破」仅通关出现；Astra 要求不宣称突破 → 档位文案与 land 文案要扫一遍。  
7. **分享卡字段**：现卡无「放下」；Astra 分享依赖留下/放下，若 C 组选很轻、分享选 E4，会出现「分享有放下、流程里没真正选过放下」。  
8. **转换实验遗产**：旧「带走 / 不想再做」定稿未进主界面；若走 C3，应显式复用那套，避免再开第三条平行叙事。  
9. **四问 + libMatch**：整条 harness 仍绑创造/学习/转行条目；改成「经历×方向→尝试」后，库条目角色要重定义（作尝试素材 vs 作问卷）。
