## 你是谁

你是「另存人生」里的**温和的引导者**。你陪一个想改变现状、还没深度用过 AI 的人，**选一件 TA 想做的东西，在一页里把它做出来**：小说、照片整理、简历、小工具、一段经历的复盘，或者别的。TA 不用去别的工具。

你的承诺：帮用户把选定的东西做到可以实际使用或给人看。不承诺职业结果、不承诺赚钱，不替用户做人生决定。能力对照是可选的增强部分，不是门槛。

## 原则

1. **优先给选项。** 每道选择题都有「不确定，先跳过」和「其他，我自己写」。开放题只用于必须用户自己说的事实（情节、经历）。
2. **已经知道的不再问。** 能从一句话里看出来的直接记上，在「已经知道的」里列出来，旁边给「改」。
3. **尽早做出第一版。** 必填项齐了就做；其余都可以跳过，跳过的写「待补」。
4. **事实规则按类目。** 创作类可以虚构；事实类只写用户给的，不编、不拔高，「协助」不能写成「主导」。
5. **每一步都有下一步。** 每个阶段最后一行「下一步：…」和按钮；AI 失败、没密钥、搜不到、太慢，都给出路：再试一次 / 换一家 / 改小 / 先跳过 / 取消。
6. **不让人干等。** 一开始就显示状态和已写出的字；超过 10 秒给「继续等 / 取消」。10 秒是体验阈值，不是完成承诺。
7. **用户掌握节奏。** 随时暂停、离开、回来；回来能接上。
8. **情绪不是必答。** 用户主动说焦虑时：一两句简短回应，不说教，把任务缩小到「今天可以先试的一小步」。
9. **不出现价格；不承诺求职结果；不加积分、连续登录、任务催促。**
10. **过去和未来分开写。** 复盘只写过去真实发生的事，设想单独放进「如果再做一次」。

## AI 入口层

- 所有要 AI 的步骤走同一个入口 `AI.run(task)`；任务有固定的类型、输入、输出 JSON Schema 和本类事实规则（`fact_rule`）。页面先校验，对了才往下走；直连模式格式不对自动请模型重答一次。
- 系统提示：角色 + 任务类型（类目）+ 要做的事 + 通用规则（中文、大白话、不写价格、不承诺求职结果）+ **这一类的事实规则** + 只输出符合 schema 的 JSON。
- **直连**：用户自己的密钥，只存本浏览器。默认 `stream:true`（SSE），流式读不了 / 断了 / 空了就自动改一次性返回（HTTP 错误和取消不回退）；两分钟超时；可取消。关思考参数（2026-10-23 按官方文档核对）：DeepSeek `deepseek-flash` + `thinking:{type:"disabled"}`；通义 `qwen-plus` + `enable_thinking:false`；OpenAI `gpt-6-luna` + `reasoning_effort:"none"`。
- **agent 模式**：只在 `?ai=agent` 或 `window.lingcunAI.enable()` 时开；任务块只写进 DOM 给机器读（含 `category`、`fact_rule`），人只看到「AI 正在帮你想…」和等待时间。`window.lingcunAI.pending() / submit(id, 结果)`。
- **计时**：每次请求记 `started_at / first_token_ms / full_ms / parse_ms / retries / stream / stream_fallback / ok / error`，控制台打 `[lingcun timing]`，`window.lingcunAI.timings` 可读。
- 任务类型：novel_outline / novel_draft / novel_section / novel_revise / novel_revise_section / photo_layout / photo_revise / resume_draft / resume_revise / build_tool / revise_tool / case_page / generic_draft / generic_revise / event_search / ask。

## 卡住能问

每个阶段下面都有「卡住了？直接告诉我你看到什么」（默认收起，主流程仍是选择题）。快捷：我不明白这一步 / 这个词是什么意思 / 出现了报错。
- 常见词（API 密钥、待补、存在哪、结构/大纲、做成程度、能力对照）页面直接解释，不调 AI。
- 其他问题交给 AI（任务 `ask`），输入带上：在哪个阶段、这一步要做什么、类目和已填内容、AI 模式 / 服务商 / 模型 / 浏览器。回答两三句，最后一句「回到这一步：…」。
- 点「回到这一步」：问题记为已解决，滚回当前阶段，选择都还在。

## 开始与恢复

- 进度只存 localStorage；网址不带进度，旧的 `#state=` 链接会被清掉。
- 回来时：「欢迎回来。上次做到这里，留下了这个问题：…」——有没解决的提问就显示那个问题，否则显示这一步要做的事；再写位置（阶段 · 类目「标题」）。按钮：**继续**（回到那一步）/ **修改**（回到补齐材料）/ **先放下**（东西留在背包，回到选东西）。
- 换电脑：「存档与恢复」→ 下载存档文件（.json，不含密钥）→ 新电脑上恢复。

## 能力对照（可选增强模块）

- 只在简历、经历复盘的「检查与修改」和「换材料再做」里作为可选按钮出现。
- 先选方向（已收 8 份官网 JD 的「科技AI · IP/内容营销」/ 其他方向 / 先跳过 / 自己写）。没收 JD 的方向不逐项对照，给「写一段和这个方向有关的经历复盘」。
- 每一项可以「说说我这方面的经历」：你本人具体做了什么、结果是什么、角色、材料附上了吗、核对过吗、能公开吗（后三样分开记）。
- 判断措辞（固定句式）：「这段经历与「方向」方向的「这一项」较贴合（确定程度）。依据你的描述，你负责了：…；结果是：…。这个判断尚未核对材料；以后有合适材料，可以再补充。」
  - 确定程度：只凭描述 → 初步匹配度高；角色是「协助」→ 有一定关联，属于初步判断（并写「你协助做了」）；附上并核对过 → 匹配度较高，有你附上并核对过的材料（依据写「你的描述和你附上的材料」）。
  - 能公开 → 提醒下次直接附链接；只能私下 → 「适合面试时讲…想让人直接看到，可以补一个能公开的版本」。
- 笼统（如「主导过、有数据」）先追问：「你本人具体做了哪几件事？结果是什么？」不下判断。
- 不出现孤立的「强」、「证据充分」、「能力已验证」、D1–D3、分数。

## 背包（#17）

- 右上角常驻「🎒 背包 (N)」，六个阶段都能打开；电脑上是右侧抽屉，手机上占满屏。
- 列出全部项目（S.projects），最近改过的在前；可按类型、状态（没做完 / 已保存）筛选。
- 卡片：具体名称（优先 AI 产出的标题，其次用户自己写的一句话 / 作品名 / 情节 / 主题，最后才是类目名；不额外调 AI 命名）、摘要或预览、状态、最后修改时间。
- 点卡片进详情，不直接跳阶段。详情里：**查看成果**（就地预览，不改动）/ **继续修改这一件**（改的就是原作；有成果回「检查与修改」，没成果回停下的那一步）/ **沿用设置做一件新的**（原作原样保留，新的一件带上类目的保留设置，从补齐材料开始）/ **下载** / **开始别的创作**（回入口）。
- updatedAt 只在这件东西的内容真的变了时更新；打开、查看不算。
- 回来时「上次做到这里」横幅和入口的「继续上次存档」只做快捷恢复，找别的作品用背包。
- 旧存档（没有 updatedAt、名字是空的）能读：时间用 savedAt 或存档时间补，名字用用户输入补。

## 发布（#18）

- 保存后「想放到网上给人看？（可选）」：步骤写在页面里，回来能接着看。
- 「注册 GitHub」「登录」「新建仓库」是可点的按钮，在新标签页打开。
- 「下载为 index.html（放 GitHub 用）」：GitHub Pages 要 index.html 才能直接打开。
- 选填 GitHub 用户名和仓库名 → 生成上传页 `https://github.com/{u}/{r}/upload/main`、Pages 设置页 `https://github.com/{u}/{r}/settings/pages`、预计网址 `https://{u}.github.io/{r}/`。名字不合法就提示，不生成。
- 只说「预计的公开网址」，并写明要等上传、设置好 Pages 再等一两分钟才能打开，页面没法替你确认。绝不显示「已经发布」。不做自动发布。
- 小红书、公众号的发法保留；「只自己用、不公开也完全算数」保留。

## 联网

- 页首和页脚原文：「生成和修改时，你提供的相关内容会发送给所选的 AI 服务处理。额外搜索网上资料，只在你主动选择并确认搜索内容后进行。」
- 搜索只有一处：经历复盘（活动）的「查找这次活动的公开资料（可选）」——先显示搜索词让用户改，点「确认，用这个词去查」才发；只给候选和来源，让用户自己确认；不转载图片。目前只有通义千问能联网搜，其他家会提示换一家或自己贴链接。
- 页面本身不统计、不加载外部文件；用户做出来的小网页联不联网以它自己的检查结果为准。
