# 另存人生 v0.0.18 · 自测清单

> v0.0.18（2026-10-29）＝ v0.0.17 页面壳 + issue #58（refs #23）。主路径改成人生试玩，四问不再走上屏。`selftest18.js` **90/90**，断网。

## 改了什么
- 首页主句：「如果保留过去的经验，换一种接下来的生活，你想试试什么？」副句「花几分钟，给自己留一个新方向。」主按钮「开始这一版」。
- 带上过去：做过的事 / 想改的事。宽屏（≥900px）左语音、右例子和打字。太短不进下一屏。
- 留下与放下：点「带走 / 放下」，背包只装经验碎片。没有带走不能「选好了」。拆不出时给示例，可自己写，或「这些都不像我」回去重说。
- 好奇方向六项：表达 / 科技 / 身体 / 手作与现场 / 工作方式 / 其他。页面上看不到创造 / 学习 / 转行。
- 仍只给一条「我想试试」，依据是带走 × 方向。不像我会换一句；连续两次给出换方向或回去改带走/放下。「改一句」断网时明说没顺成，字还留着。
- 另存成功：一点即成，不按住。标题「另存成功」。开图只有一句说明，不是链接、不是按钮。
- 分享卡：带走 / 放下 / 想试试，可编辑可隐藏；主问「你会带走什么？」。隐藏后图片和文字都不带该段。
- H1：「改 / 编辑 / 隐藏」是 22px 小描边，不是实心主按钮（实测高 22、字号 11、底透明）。
