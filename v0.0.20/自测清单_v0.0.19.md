# 另存人生 v0.0.19 · 自测清单

> v0.0.19（2026-10-31）＝ v0.0.18 页面壳 + issue #60（refs #23）。整站换成像素蓝奶油；「留下与放下」改成对话框里的贴纸，拖进背包或纸箱，也可以点选。第一屏 8 张，可以换一批。`selftest18.js` **92/92**，`selftest19.js` **50/50**，断网。

## 改了什么
- 色板换成蓝底 `#5E72B5`、奶油面 `#F7F0DF`、描边和正文 `#232B55`，另有深一档的蓝、深一档的奶油、高光。卡片、按钮、输入、弹层、分享卡都是阶梯直角、粗描边、硬投影。直接落在蓝底上的字用白，奶油面上的正文用深蓝。
- 建成的 `page/index.html` 里不再有 `#F3F0F9 / #C9B8F5 / #231C45 / #2A2152`，也没有 `backdrop-filter` 和 `blur()`。`onblur` 还在，那是输入框失焦的事件名，不是视觉模糊。
- 「留下与放下」：像素对话框，8 张贴纸轻微浮动；系统开了减少动态效果就停。背包＝带走，纸箱＝放下。拖的时候原贴纸变淡，靠近落点换成 active 图标，放下后换成 done，下面出小标签。点小标签回到对话框。松在外面弹回。点贴纸会出现「带走 / 放下 / 取消」，键盘和读屏走同一条。
- 「更多…」自己加一个词，最多 16 字，去掉首尾空格，不重复。可以进对话框，也可以直接放进背包或纸箱。
- 「下一步」要先放进至少一张才亮。背包是空的就提示「至少带走一条，后面的尝试才站得住」，停在这一屏。结果仍写入 `take[]` / `leave[]`。
- 候选词先从用户前面说过的话里抽，再从经验碎片词库补，最后才是好奇方向的词。去重之后不少于 16 个。「换一批」只换还在对话框里的，已经放下的不动。拖走一张就从剩下的词里补上，对话框里尽量保持 8 张。
- 纸箱图标重画了：开口的箱盖、箱口、正面一条胶带。默认、靠近、放下三种都换过。
- `apple-touch-icon.png` 按新的 `app-icon.svg` 重栅成 180×180。页面里没有别的位图应用图标。
- 分享图改成蓝底奶油面，硬边框，没有旧的淡紫渐变。

## 自测里改过的旧断言
- 每张卡片上的「带走 / 放下」按钮没有了，改成贴纸上的点选条。`selftest18.js` 改为点贴纸再点「带走 / 放下」。
- 主按钮文案是「下一步」，不再是「选好了」。位置仍在首屏。
- 只放下、背包还空着时，「下一步」会亮；点下去才出现「至少带走一条…」，不再一直禁用。多了一条「只放下时下一步会亮」（手机、桌面各一，所以 90 变成 92）。
- 经历太短时不再出现「自己写一条」的两个输入框，改成词库贴纸、「更多…」和「这些都不像我」。
