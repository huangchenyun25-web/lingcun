# 另存人生 v0.0.20 · 自测清单

> v0.0.20（2026-11-08）＝ v0.0.19 页面壳 + 第三十三批。首屏、留声机、另存成功的界面还在。理解改成走现有中转：对得上原句才显示；对不上就停在「整理，不是理解」，不用模板盖住模型结果。`selftest18.js` **94/94**，`selftest19.js` **50/50**，`selftest20.js` **48/48**（断网整理），`selftest21.js` **19/19**（合同、模拟、一次真实中转）。没有新建 GitHub issue。

## 改了什么
- 首页标题仍是「如果保留过去的经验，换一种接下来的生活，你想试试什么？」，按逗号折成三行，字号收到大约 22–28px。「另存人生」不再是奶油小方块，底下的线只托住这四个字。「开始这一版」跟在副句下面，手机 390×844 和桌面 1280×720 的第一屏都能看到。
- 按住说话换成像素留声机（喇叭口、喉管、柜子、唱片、摇把），用蓝 `#5E72B5`、奶油 `#F7F0DF`、海军蓝 `#232B55`。按钮不再套方框。读屏名称仍是「按住说话，松开结束，最多 30 秒」。录音时唱片按步进转动；系统开了减少动态效果就停。打字、重听、重来、就这样都还在。
- 留下与放下不再把职业词库或方向词补进对话框。只按标点切开这一次写下的话；一句不超过 16 字就整句留下。更长、又没有「但是 / 以及 / 然后 / 或者 / 而且 / 不过 / 可是 / 因为 / 所以」的，不猜着切开，页面写出原话，并打开「自己加一个词」。多于 8 条时仍是 8 张加「换一批」，换出来的也必须在原话里。拖走一张不会再用无关词补位。
- 尝试句只引用用户带走、放下的原话，以及用户选的方向。不再写「擅长」，也不再塞第一步库里的句子。
- 另存成功收成一块奶油面板：小的像素标记、方向、这一步、「看这一版」。开图仍是说明句。分享和星图还是原来的去处。减少动态效果时标记不闪。
- `window.__lingcun20.setEvidence` 可以以后挂「带来源的公共例子」。没写来源的条目会被丢掉。这个列表现在是空的，也不会写进贴纸、尝试或另存结果。本版没有放进任何公开研究或模拟人物。

## 自测里改过的旧断言
- `selftest18.js`：例子「办过线下活动策划，负责现场和讲故事」现在拆成「办过线下活动策划」「负责现场和讲故事」，不再要求「现场观察 / 讲故事 / 活动策划」。另存成功改为能看到方向和这一步（用户若先改过尝试句，成功页用改过的那句）。弱输入「嗯嗯嗯嗯嗯嗯」不再凑满 8 张词库贴纸。
- `selftest19.js`：不再要求普通、弱、空输入都至少 16 个候选，也不再要求方向词排在后面。进入时是原话有几条就几条。放进背包后不补无关词。不足 8 条时「换一批」隐藏。拖拽、点选、键盘、更多、空背包提示、色板和对比度仍测。

## 真实中转的一次（不是盲测，也不是普遍成功）
输入：「我不是想辞职，只是不知道每天写这些东西有什么用。下班只剩二十分钟，也不想花钱。」

模型抄出的原句通过了位置核对，页面写明「格式检查过，并不证明它真的懂」：我不是想辞职 / 只是不知道每天写这些东西有什么用 / 下班只剩二十分钟 / 也不想花钱。一条没对上原文的推测被丢掉，没有显示。

随后的一种做法是：「翻出最近写过的三份东西，各写一句当时想解决什么。」为何里补上了原句「只是不知道每天写这些东西有什么用」。看什么：这三份里有没有重复的目的。何时停：翻着觉得更烦就停下，不用凑满三份。没有劝辞职，也没有劝花钱。

模型有时把原文当编号，下标也会偏。页面对得上的原句会改回正确下标；对不上的整段不显示。这只说明这一次的格式门开了，不能当成语义已经验过。

## 做得到的，和做不到的
做得到的：在线时走现有免费中转（或用户自己的密钥），不另加账号。对得上原文的句子才进「留下与放下」。推测若不是原句就丢掉。限制对不上的做法（例如原话不想辞职，却建议辞职）整条不显示。断网、关掉中转、请求失败，都写明是整理，不是理解。用户改过的尝试句不会被本地模板盖掉。研究池只放了几条短摘录和抽象提法，对不上就不显示；模拟人物没有写进页面。

做不到的：格式门不证明模型懂了。超过 16 字、又没有「但是 / 以及」这类连词的句子，离线不会切开。真实模型这一轮只跑过上面一条，不能说普遍有效。自测里的例子是开发时写的，不是留出的盲测集。语音识别仍靠浏览器。没有新密钥，也没有改线上密钥或重新部署中转。
