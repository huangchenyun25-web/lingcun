选一件你想做的，在这一页里一步一步做出来。不打卡、不考试、不承诺求职结果。

AI 设置：用你自己的 API 密钥

页面里需要 AI 的几步（做出第一版、按你说的改、卡住时回答你），都用你在这里填的密钥，在这一页里直接跑。以后随时能换一家，或者忘掉密钥。

这一页是由一个 agent（比如 Codex、Claude Code、Grok Bot）替你打开的，它会在后台帮你想，你只要像平常一样做选择。想自己来，在下面填好密钥点「保存」就行。
说清楚三件事：① 密钥只存在这台设备的这个浏览器里（localStorage），不会写进存档文件，也不会发给另存人生；② 生成和修改时，你提供的相关内容会直接从你的浏览器发给你选的那家 AI 服务处理；③ 密钥能花你账户里的额度，别在公用电脑上存，用完可以点「忘掉密钥」。

可选：能力对照 · 这段经历和哪个方向较贴合

存档与恢复

进度自动存在这台设备的这个浏览器里（localStorage），网址里不带任何进度。同一个浏览器再打开这一页，会看到「上次做到这里」。要换电脑或换浏览器：先下载存档文件，到新设备上用「从存档文件恢复」。存档文件不带 API 密钥。
