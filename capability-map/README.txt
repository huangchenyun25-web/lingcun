三天能力对照
============

这是什么
--------
一个单页工具：你填 3–8 件真实做过的事，页面对照「出海营销 / IP 营销 / PM」三列，
给每件事标「已有 / 可补 / 对不上」。不替你选职业、不排名。

怎么打开
--------
双击 index.html，或拖进浏览器。不需要联网、不需要安装。

数据存在哪
----------
只在这台电脑的浏览器 localStorage 里，不上传。

你以后能改什么
--------------
- 三条路的名字（改 TRACKS）
- 关键词启发规则（改 CUES）
- 「短期可补」最多几条（现在是 5）
- 文案与样式（都在同一个 index.html 里）

换一组事例再跑
--------------
结果页底部按钮会清空输入与本地记录，方便你重新填。
