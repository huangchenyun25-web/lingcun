AI 设置

这一页是由一个 agent（比如 Codex、Claude Code、Grok Bot）替你打开的，它会在后台帮你想，你只要像平常一样做选择。想自己来，在下面选一种就行。
免费体验额度（默认）

不用注册、不用密钥：另存人生的中转服务替你调用 DeepSeek，每人每天有一定次数，够走完一局。中转服务只转发，不保存你的内容。

用自己的密钥

填你自己的 API 密钥后，页面直接从你的浏览器调用你选的那家，用的是你自己的额度，不占免费体验额度。以后随时能换一家，或者忘掉密钥。

说清楚三件事：① 密钥只存在这台设备的这个浏览器里（localStorage），不会写进进度文件，也不会发给另存人生；② 生成和修改时，你提供的相关内容会直接从你的浏览器发给你选的那家 AI 服务处理；③ 密钥能花你账户里的额度，别在公用电脑上存，用完可以点「忘掉密钥」。
