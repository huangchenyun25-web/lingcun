一、一局 = 一次登陆
------------------
选这一局 → 补齐材料 → 做出第一版 → 检查与修改 → 确认登月 → 之后
- 入口：【记录】【改写】【创造】，每个都写清「这一局会带走什么」；也可以直接说一句想法，或看看例子。
- 登月前要确认（文字：读过、愿意留下；经历：核对过事实；小工具：亲手试过、核心功能能用），不确认就不登月。
- 登月后：动画 +「这一步虽小，对我来说确实是大突破」+ 完成卡（可存成 PNG、可分享）+ star 入口 + 下一步（继续修改 / 下载作品 / 开始下一局 / 今天先到这儿）。
- 顶部航线：小飞船随进度前进，始终写「离月球还有 N 站」；补齐材料是一叠卡片，一次一张，手机可左右滑。
- 等 AI：飞船穿过星云，生成的字一段一段流进来。
- 确认登月：「按住蓄力，松手发射 」；键盘回车 / 空格、读屏软件可直接发射；「减少动画」时是普通按钮。
- 登陆动画（抽象 SVG 宇航员，没有脸）：默认 A（推进光降落 → 月尘 → 插旗 → 挥手），网址加 ?landing=b 换成 B（火箭划弧 → 弹出 → 插旗 → 星芒）。落地后镜头拉远进星图：「下一局从「月球」出发」。系统开了「减少动画」时不播放，直接显示落好的样子。

三、AI 由谁来跑
--------------
1. 免费体验额度（默认）：经过另存人生的中转（../relay/，Cloudflare Worker）转给 DeepSeek deepseek-flash，关思考，流式。
   中转地址写在 _build/p2.js 的 RELAY_URL，现在是 https://lingcun-relay.lingcun.workers.dev（已上线）；网址加 ?relay=off 可关掉中转（测试用）。
   本机测试可以用 ?relay=http://127.0.0.1:端口（只接受 127.0.0.1 / localhost）。
   额度用完：提示「明天再来，或者用自己的密钥继续」。
2.  用自己的密钥（直连）：右上角「AI：…」→「用自己的密钥」。和 v0.0.9 一样：DeepSeek / 通义千问 / OpenAI 兼容，SSE 流式 + 回退 + 修复重试。
   密钥只存在这个浏览器（lingcun_v010_apikey），不进进度文件，可以「忘掉密钥」。
3. agent 模式：?ai=agent 或 window.lingcunAI.enable()，任务块和提交方式同 v0.0.9。新增 inputs.user_idea（用户的原话）。
4. ?ai=mock：测试专用；可加 &mockdelay=毫秒。

计时：window.lingcunAI.timings（mode 多了 relay）。
本机小统计：window.lingcunAI.metrics（started / completed / card_seen / shared / star_seen / star_clicked），存在 lingcun_v010_metrics；
只是这台设备上的点击次数，不上传，也不等于 GitHub 上的 star 数。页面最下面「小统计」能看到。
