另存人生 v0.0.7 · 先做出第一件东西（测试版）
==========================================

打开方式
--------
双击 index.html，或放到 GitHub Pages 的任意子路径下。不需要安装、不需要联网、不需要 API key。

数据存在哪
----------
只在这台设备的这个浏览器里（localStorage），同时写在网址最后的 #state= 里。
换设备或清除浏览器数据时，用「复制存档链接」得到的链接恢复。

流程
----
三句话 → 先动哪一头（不想做现在的事 / 想做别的事 / 暂时没想法）
→（想做别的事：讲经历 → 方向推荐 → 能力对照 → 选题）
→ 项目卡 + 给 AI 的说明 → 在你自己的 AI 里做 → 回来报告 → 你做成了什么 → 轻量化资产页
