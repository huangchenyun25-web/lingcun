# 另存人生 v0.0.7 · 自测清单

> 对象：`v0.0.7/page/index.html`（双击打开即可；也可放到 GitHub Pages 子路径下测）+ 《引导协议_v0.0.7》。
> 核心规则（「断」）：**每个节点结束时，页面都要交给你一个具体的下一步动作。** 下面每一步都写了「应该看到的下一步」；看不到，就记一条卡点。

## 二、进度记忆

- [ ] 刷新页面：顶部出现「欢迎回来，上次停在……现在要做……」，点「接着做」回到原处。
- [ ] 复制存档链接，在**另一个浏览器 / 无痕窗口 / 手机**打开：进度完整恢复（三句话、对照标签、资产卡）。
- [ ] 「存档与恢复」里写清楚了：清除浏览器数据或换设备又没有链接，进度就找不回来。
- [ ] 页面上没有任何固定天数的提醒。

## 三、真 AI 交接（最重要，至少两个不同的 AI）

把「给 AI 的说明」原样贴进去，记下：
- [ ] 第一条回复是否只复述最小版本 + 只问一个问题？
- [ ] 之后是否每次只推进一步、只问一个问题？（记下第几轮开始一口气吐完）
- [ ] 改代码时是否给完整 `index.html`、没有省略号？
- [ ] 做出能打开的文件后，是否自动输出进度回传码？字段名有没有被改？
- [ ] 卡住两轮后是否自动输出回传码？
- [ ] 发「自检」是否逐条对照最小交付标准？
- [ ] 没问统计时，它有没有自己加统计代码？问了之后是不是只推荐不蒜子？
- [ ] 未缓存方向：它收的 JD 有没有标「未核实」、有没有编链接？
- [ ] 把回传码贴回页面，页面能不能读出来？

## 四、ChatGPT 提的四个指标（每位测试者都记）

最好包括：没有 GitHub、没写过代码、没有明确职业目标的人。测试时创始人不帮忙，只观察。

| 指标 | 怎么记 | 结果 |
|---|---|---|
| 1. 能否**独立**拿到第一个可执行项目？ | 从打开页面到复制说明，用了几分钟、问了几次人 | |
| 2. 能否把指令交给自己的 AI 并推进？ | 到「做出来了」用了几轮；AI 有没有跑偏 | |
| 3. 卡住之后，是否知道怎么继续？ | 卡在哪；有没有用「卡住了」/ 恢复指令自己走出来 | |
| 4. 完成或中断之后，是否有理由回到另存人生？ | 有没有回来；回来是为了什么（报告进度 / 看资产页 / 补证据 / 没回来） | |
